## 🆕 Añadir un nuevo proceso

Para documentar un nuevo proceso:

1. Crea un nuevo archivo `.md` en esta carpeta
2. Usa el formato del ejemplo como guía
3. Añade una entrada en la tabla de arriba
4. Asegúrate de que incluya: objetivo, responsables, pasos, y puntos de control
