## 🆕 Añadir un nuevo procedimiento

1. Identifica la categoría correcta (o crea una nueva)
2. Crea un archivo `.md` descriptivo
3. Usa formato de pasos numerados
4. Incluye: objetivo, requisitos previos, pasos, y resultado esperado
