# 📘 Manual de Operaciones - Empieza de Cero

Este repositorio contiene todos los procedimientos, procesos, checklists y políticas que rigen el día a día de nuestra empresa. Está diseñado para ser consultado por cualquier miembro del equipo en cualquier momento.

## 📁 Estructura del Repositorio

```
docs/
├── README.md              # Índice general del manual
├── procesos/              # Procesos de negocio (flujos completos)
├── procedimientos/        # Procedimientos específicos (paso a paso)
├── checklists/            # Listas de verificación
├── politicas/             # Políticas internas de la empresa
└── anexos/                # Documentos de apoyo, plantillas, ejemplos
```

---

## ✏️ Cómo Actualizar el Manual

1. Edita los archivos `.md` directamente en GitHub o clona el repositorio
2. Los cambios en la carpeta `docs/` se reflejan automáticamente en el sitio web
3. Usa Markdown para formato de texto: títulos, listas, tablas, enlaces, etc.
